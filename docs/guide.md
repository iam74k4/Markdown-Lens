# Markdown Lens 利用ガイド

[← 画面付きの機能紹介へ](../README.md)

差分が見えるMarkdown本文を、そのまま編集できるVS Code / Cursor拡張です。

本文には追加・変更を緑のマーカーで表示し、変更前・削除内容はその場で展開できます。「変更前・差分を見る」を開くと赤系のマーカー＋取り消し線も表示します。不要な変更は「戻す」、読み終わった変更は1件ずつ「確認済み」。アカウントやAI APIキーは不要です。

現行の拡張機能の表示名・コマンド名は **Markdown Lens** です。

## インストール

VS CodeまたはCursorでコマンドパレットを開き、`Extensions: Install from VSIX...`（VSIXからのインストール）を選んで `markdown-lens-0.14.0.vsix` を指定します。VS Codeでは拡張機能パネルから `@id:iam74k4.markdown-lens-review` を検索する方法もあります。Cursor向けOpen VSXは公開準備中です。

## 使い方

1. **AIで修正する前に**、作業フォルダーを開きます。エクスプローラーの **Markdown Lens · 未確認** に「監視中」が表示されるまで待ちます。初回読み込みで比較元を保存します。
2. エディタ右上の差分アイコン、またはコマンドパレットの **Markdown Lens: 変更プレビューを開く** を実行します。一覧の対象外のファイルは、初回にプレビューを開いた内容を比較元として保存します。
3. Claude Code / Codex / Cursor / 手動で、同じファイルを編集します。プレビューが自動更新されます。
4. 下部の **未確認 ○件** を見ながら、`↑` / `↓` で変更箇所へ移動します。
5. 変更の近くの **↶（戻す）** で元の内容に戻すか、**✓（確認済み）** でその変更だけを確定します。確認済みにした箇所は通常の本文に戻り、残りの差分はそのまま表示されます。
6. まとめて確認するときは、下部の **すべて確認** を押します。全件の確認が終わると確認バーが消え、「未確認の変更はありません」と表示します。

操作ボタンにマウスを重ねるか、Tabでフォーカスすると説明を表示します。通常は「Preview」で編集と差分確認を行います。「MD」でソースを表示し、「Preview」で本文へ戻ります。変更前は各変更の「変更前・差分を見る」で確認できます。文字選択時には太字・文字色・マーカー・リンクの書式バーが現れます。選択なしで開くには **⋯ → 文字の書式** または **Alt+F10**。挿入・リスト・コード・Undo/Redo・検索・目次・折りたたみ・スナップショットは **⋯** にあります。**Esc** でメニューを閉じられます。

**戻すと未保存の編集になります。** プレビュー下部の「保存」またはエディタの通常の保存操作で反映できます。エディタにフォーカスして通常のUndo（Mac: `⌘Z`、Windows/Linux: `Ctrl+Z`）を使うと、戻す操作自体も取り消せます。

「確認済み」は選んだ変更だけを比較元に取り込み、「すべて確認」は現在の全文を比較元にします。ファイル保存やGitコミットは行いません。未保存の内容も確認でき、保存状態は画面下部に表示します。

個別の確認状態はタブを閉じても保持します。確認済みの箇所をAIや人が再編集すると、最後に確認した内容との差分が再び未確認として表示されます。確認は段落・リスト・表などの変更ブロック単位です。改行コードが変わる場合はファイル全体を1件として確認します。

## 記法の保持・リンク・Git連携（0.14.0）

### 編集しても記法を変えない

Previewでブロックを編集すると、そのブロックだけをMarkdownに書き戻します。0.14.0では、書き戻しで次の記法を原文どおりに保ちます。

- 折り返した段落の改行位置と継続行の字下げ。日本語の文中の改行に空白を足しません。
- インラインHTML・HTMLブロック・HTMLコメント。Previewではソースとして表示し、`<kbd>` `<sub>` `<sup>` `<small>` `<u>` `<b>` `<i>` `<em>` `<strong>` のうち属性のないものだけを描画します。
- frontmatter（文書先頭の `---` / `+++`）。メタデータの表として表示し、「ソースを編集」で直接編集します。キーと値の形でない先頭の `---` は区切り線のままです。
- GitHubアラート（`> [!NOTE]` `[!TIP]` `[!IMPORTANT]` `[!WARNING]` `[!CAUTION]`）、脚注（`[^1]` と `[^1]: …`）、Wikiリンク（`[[Page]]`、`[[Page|表示名]]`、`[[Page#見出し]]`）。
- 数式（`$…$`、`$$…$$`、行の `$$` ブロック）。KaTeXで表示し、`\href` などの外部参照は無効です。`$5 と $10` のような金額は数式として扱いません。設定 `markdownLens.math` をオフにするとソースのまま表示します。
- 文字参照（`&copy;`）と、意味が変わるエスケープ（`\$` `\&` `\#` など）。
- 箇条書き記号、`1)` 形式の番号、`_斜体_` / `__太字__`（単語の途中では `*` に置き換え）、`~~~` や字下げのコードブロック、Setext見出し、`* * *` などの区切り線、行末2スペース・`<br>` の改行。
- 表は、内容が変わらない行と区切り行を原文のまま、編集した行もセルの余白を保って書き戻します。

数式・HTML・脚注・Wikiリンクなどは1つの部品として表示します。ダブルクリック、または選択してEnterで1行のMarkdownとして編集し、空にすると削除します。数式は「⋯ → 数式を挿入」、脚注は「脚注を挿入」（本文に `[^n]`、末尾に定義を追加）、メタデータは「メタデータを編集」で追加できます。

ProseMirrorの文書に変換すると段落が失われる構造（例: スキーマに収まらない入れ子）は、空の文書として読み込む代わりに「直接編集に対応していません」と表示し、MD画面での編集に切り替えます。

参照リンク `[text][ref]` を含む段落を編集すると、その段落のリンクは `[text](URL)` 形式になります。定義行は残し、ほかの段落の参照リンクは変わりません。

### リンク

- **⌘/Ctrl+クリック**: リンク・URLの直書き・Wikiリンク・脚注番号を開きます。`.md` は変更プレビュー、`#見出し` は文書内の見出し（GitHubと同じ規則、重複は `-1` `-2`）、それ以外のファイルはVS Codeで開きます。`http(s)`・`mailto` は確認後にブラウザーで開き、`command:` などは開きません。
- **リンク切れ**: 相対リンク・画像・見出しアンカー・Wikiリンクの行き先を確認し、波線、サブバーの「⚠ リンク切れ」、「問題」パネルに表示します。外部URLにはアクセスしません。プレビューを閉じると「問題」パネルからも消えます。`markdownLens.validateLinks` で無効にできます。

### Git・比較元

- **スナップショット・Gitと比較**: スナップショットに加え、Git HEAD、ブランチ、このファイルのコミットと比較します。比較中は確認操作を無効にし、確認済みの状態を変えません。VS Code組み込みのGit拡張機能を使います。
- **比較元をリセット**: 確認済みの内容を「現在の内容」「Git HEAD」「Gitのブランチ・コミット」「空の文書」に置き換えます。直後は「取り消す」で戻せます。
- **初回の比較元**: `markdownLens.initialBaseline` を `gitHead` にすると、初めて読み込んだファイルを最後のコミットと比較します。未追跡のファイルは全文を追加として表示します。
- **新しいファイル**: 監視を始めた後に作成されたファイルは、全文を追加として未確認にします。`markdownLens.newFiles` を `reviewed` にすると従来どおり作成時の内容が比較元です。
- **名前変更**: VS Codeでの名前変更・フォルダー移動は比較元・下書き・スナップショット・表示位置を引き継ぎます。外部ツールによる移動は、直前（10秒以内）に削除されたファイルのうち内容が半分以上一致するものを引き継ぎます。
- **変更の要約**: 「変更の要約を書き出す」（⋯、未確認一覧のタイトル、コマンドパレット）で、このファイルまたは未確認のすべてのファイルを、見出しの位置と行番号付きの差分一覧にします。

### テキストエディター

- 行番号の横（追加は緑、変更は青、削除は赤の三角）と概要ルーラーに未確認の変更を表示します（`markdownLens.editorDecorations`）。
- ステータスバーに件数を表示し、クリックで変更プレビューを開きます（`markdownLens.statusBar`）。
- `Alt+F3` / `Shift+Alt+F3`（コマンド「次／前の未確認の変更へ移動」）でテキストエディターのカーソルを移動します。変更プレビューでは `Alt+↓` / `Alt+↑` を使います。
- 「確認済みの内容とのテキスト差分を開く」で、VS Codeの差分エディターに確認済みの内容と現在のファイルを並べます。
- 「別のエディターで開く… → Markdown Lens」で、変更プレビューをエディターとして開けます。「既定のエディターを構成」で常にMarkdown Lensで開くこともできます。

### コマンドとキー

### 英語表示

VS Codeの表示言語が日本語以外の場合、画面・メッセージ・コマンド・設定を英語で表示します。

## 検索・目次・画像貼り付け・作業再開（0.10.0）

- **セルの確認**: 本文の変更セルに現れる↶／✓から操作します。見出しセル、空セル、文字色や太字の変更にも対応。行列の構成や配置指定が変わった表は表全体を確認してください。セルは同じ行・列の位置で対応付けます。
- **検索・置換**: ⋯ の「本文を検索・置換」、⌘F／Ctrl+Fで開きます。Enter／Shift+Enterで前後の結果へ移動し、Escで閉じます。「変更箇所だけ」は未確認の変更ブロックが対象です。正規表現ではなく文字列検索で、本文・表・コードを検索します。Markdown記号、リンク先、画像の説明は検索対象にしません。置換はPreviewで行い、最初の文字の書式を引き継ぎます。セルや段落をまたぐ検索と改行を含む置換は対象外です。2,000件を超える場合は絞り込みを促す「+」を表示し、全件置換を無効にします。
- **目次**: ⋯ の「見出しナビゲーション」で文書直下の見出し1〜6と未確認件数を表示します。親見出しの件数には子の変更を含みます。移動先の折りたたみを開き、変更箇所だけ表示中でも対象の見出しを表示します。
- **画像貼り付け**: 本文または現在のMarkdownソース欄へPNG／JPEG／GIF／WebPを貼り付けます。1枚10MBまで、同時に複数ある場合は最初の対応画像を使用。保存先は文書の隣の `.markdown-lens-images` で、ランダムなファイル名を使い既存画像を上書きしません。画像は即時保存、Markdownは明示保存です。Undoや下書き破棄では画像ファイルを削除しません。外部変更で挿入できない場合も保存先を表示します。
- **作業位置の復元**: ファイルごとに表示位置、見出しの開閉、変更箇所だけ表示、ソースの開閉を拡張ストレージへ保存します。本文では見出しを手がかりに位置を復元し、見出しが変わった場合はスクロール位置を使います。文書の大幅変更・画像の遅延読み込みで位置がずれる場合があります。検索語や選択範囲、Undo履歴は復元対象外です。

## 日本語入力と下書き（0.9.1）

日本語の変換中は差分マーカーの更新を待ち、確定後に更新します。保存・確認・戻すは入力確定後に操作してください。外部で同じ文書が変更された場合も、確定した下書きを保持して競合を表示します。
表のセル内では **Shift+Enter** で改行できます。保存時は`<br>`になり、再読み込みしても改行を保持します。Preview内のコピー／切り取り→貼り付けはリンク先・画像パス・チェック状態を保持します。引用やリスト内の参照リンク定義は、本文の編集で必要になる場合に文書先頭へ保持します。


受信した下書きの保存が終わるまで、閉じたタブの開き直しを待つようにしました。長いMarkdownをソース欄へ貼り付けた場合は、少し間を置いて本文表示を更新します。保存や表示切り替えでは最新の入力を同期します。Markdownファイルへの書き込みは引き続き明示的な保存で行います。

## 視覚的なレビュー（0.4.0）

- **確認の取り消し**: 確認後の「✓ 確認しました → 取り消す」で、直前の1操作を未確認に戻します。本文と保存状態は変わりません。個別確認・全件確認の両方が対象で、タブを閉じるまで利用できます。
- **未確認ファイル一覧**: エクスプローラーにファイル名と変更件数を表示。レビューのタブを閉じていても監視します。初回読み込み以前の履歴は復元できません。最大1,000ファイル、`node_modules`・`.git`・`dist`・`build`・`.next`・`vendor` は対象外です。
- **変更箇所だけ表示**: フィルターアイコンで変更のないブロックを折りたたみます。必要な部分はクリックして個別に展開できます。
- **スナップショット**: カメラアイコンで現在の文書を保存し、履歴アイコンから比較します。確認済みの比較元は変更しません。スナップショット比較中は確認操作を無効にし、「確認済みの内容」を選ぶと通常レビューに戻ります。1ファイル20件まで保存でき、履歴から個別に削除できます。下書きの編集中は先に保存してください。
- **画像プレビュー**: ワークスペース内の相対パスの画像（PNG/JPEG/GIF/WebP/AVIF/SVG）を本文に表示します。フォルダー外への参照、外部URL、画像内のリンク操作は読み込み対象外です。画像ファイル自体のピクセル差分は比較しません。
- **Mermaid**: fenced code blockの `mermaid` を図として表示。単純なフローチャートは箱・矢印の追加を緑、削除を赤と破線、ラベル等の変更を黄で強調します。変更前・差分・変更後を切り替え、図の変更全体を戻す・確認済みにできます。
- **表のセル差分**: 構造が同じ表では変更セルと変更文字だけを強調。行・列の構成が変わる場合は前後表示になります。行列構造が一致する表ではセル単位の確認・復元に対応します。構造変更は表全体が対象です。
- **段落の移動**: 内容が完全一致する一意のブロックを「↕ 移動」として表示。移動元・移動先をまとめて1操作で確認・復元できます。重複段落や内容も変わった移動は、通常の追加・削除として表示します。

Mermaidの図の差分は、安定したノードIDを持つ基本的なフローチャートが対象です（長方形、角丸、円、菱形、円柱等・通常の接続）。サブグラフ、独自スタイル、複雑な接続やほかの図種は、変更前後を並べて比較します。差分図では前後の要素を同じ図に配置しますが、原図と同じ座標配置は保証しません。最大30,000文字・200接続、図の差分は各版80ノード・120接続までです。設定ディレクティブとfrontmatterは実行せずソース表示に切り替えます。不正な構文でもMarkdownは保持し、ソースを確認できます。

AIによる変更要約・文章と図の整合性チェック・図を直接操作する編集は今後の機能です。現在はAI APIを呼び出しません。

## 表を読みやすく表示（0.5.0）

表の変更箇所の **変更前・差分を見る → 広く表示** で表だけを拡大します。Escapeまたは「本文に戻す」で戻ります。

- 現在値を中心に表示し、変更セルには常にマーカーを残します。セルを選ぶと下部に変更前後・全文を表示します。削除で空になったセルは「削除」と表示し、削除された表は赤系のマーカーで示します。
- 長い説明は2行にまとめ、選択した行を薄く強調します。セル内の矢印キーで隣のセルへ移動でき、Enterで詳細を開きます。
- 見出しと先頭列を固定し、表の中だけ縦横にスクロールできます。数値列は右揃えにし、Markdownで指定された配置があれば優先します。
- 見出しの列境界をドラッグ、またはTabで列境界へ移動して左右キーで列幅を調整します。「列幅を戻す」で内容に合わせた初期幅に戻せます。
- **変更行** で変更された行だけに絞れます。同じ値が繰り返される短い分類列がある場合は、選択してグループ表示できます。元の行順に戻すには「グループなし」を選びます。
- Previewの表示幅を広げるアイコンも使えます。表のTab移動、行・列の編集、保存の動作は従来どおりです。

幅・並び順・グループ・折りたたみは画面内の表示設定で、Markdown本文には保存しません。内容の更新時には最新の表から表示を作り直します。拡大中に外部更新が入った場合は拡大表示を閉じ、最新内容を表示します。

2,500セルを超える表は、操作負荷を抑えるため通常の差分表示とスクロールに切り替えます。表全体の確認・復元は引き続き利用できます。

## 本文の編集と差分を統合（0.6.0）

通常は **本文** を開いたまま、読んで・直して・確認できます。

- **インライン差分**: 編集できる文字の上に緑のマーカーを表示。変更の近くに「戻す」「確認済み」を置き、変更前・削除内容は折りたたみで表示します。書式やURLだけの変更もカードに残ります。
- **手動編集もすぐ比較**: 入力後の下書きを確認済みの基準と比較します。マーカー更新では本文を書き換えないため、入力位置とWYSIWYGのUndo履歴を保持します。入力確定前・比較更新中の確認操作を抑止します。
- **Markdownソース**: 「Markdown」から現在のソースを直接編集できます。「確認済み」「比較元」は読み取り専用。広い画面では横並び、狭い画面ではソースに切り替わり、閉じると本文へ戻ります。
- **書式**: 見出し1〜6、太字、斜体、取り消し線、引用、区切り線、箇条書き、番号付きリスト、チェックリスト、リンク、インラインコード、コードブロック。
- **表**: セルを直接編集。Tab / Shift+Tabで移動し、上下の行・左右の列を追加できます。左・中央・右揃えはMarkdownの仕様に合わせて列全体に適用します。見出し固定と表内スクロール、編集領域の拡大に対応します。
- **画像**: 相対パスと説明を入力して挿入。ホストで許可されたワークスペース内のローカル画像を本文中に表示します。画像を選択して挿入ボタンを押すとパス・説明を変更できます。外部画像は説明とパスだけを表示します。
- **Mermaid / コード**: 言語名を変更できます。Mermaidは本文内に図を表示し、「Mermaidソースを編集」を開いてコードを直接修正すると図を更新します。不正な構文は図だけをエラー表示し、入力したコードは保持します。
- **変更前・差分を見る**: 変更箇所ごとの折りたたみから、書式付きの前後差分・削除内容・元のMarkdownを確認できます。表の拡大・分類・セル前後比較もここから使えます。Mermaidの変更前／差分／変更後は本文内の図で切り替えます。
- **保存**: 画面下部の「保存」または `⌘S` / `Ctrl+S` で同じ `.md` ファイルへ保存します。

入力中の内容は専用ストレージに下書きとして保持し、タブを閉じても復元します。下書きの確認・復元では、まずエディタの文書へ未保存の編集として反映します。Preview／Markdownの切り替えや比較を開く操作では、下書きを保存しません。ディスクへの保存は明示操作で行います。下書きがある状態で「戻す」を押すと、選んだ差分だけを戻し、他の変更は残します。

外部のAIやエディタが元のファイルを更新した場合は、下書きを上書きせず競合を表示します。「下書きを別タブに開く」で退避し、「下書きを破棄して最新を読み込む」で最新内容を読み込めます。自動マージは行いません。

本文のUndo/RedoはWYSIWYGの編集履歴です。ソース入力欄には入力欄のUndoを使います。ソース変更の読み込み・外部更新・「戻す」による本文の再読み込みではWYSIWYG履歴を初期化します。「戻す」操作自体はVS Code/Cursorの元のMarkdownエディタでUndoできます。

編集していないブロックのMarkdown表記は保持します。変更したブロックはMarkdownとして書き直すため、箇条書き記号、空白、表の区切りなどが整う場合があります。表は結合のない基本的な表が対象です。画像のピクセル編集、図のドラッグ編集、数式や文字色・マーカー以外の任意HTMLのWYSIWYG編集は対象外です。元の表記はソースで確認・編集できます。

## 文字色とマーカー（0.9.0）

1. 本文・見出し・表のセル内の文字を選択します。
2. ツールバーの **A（文字色）／マーカー** からパレットを開きます。
3. 8色のプリセットを押すか、カラーピッカー／`#RRGGBB` 形式で色を指定して「適用」します。
4. 「文字色を解除」「マーカーを解除」で、それぞれ選択範囲の色だけを外せます。Undo／Redoにも対応します。

色は下書きに反映し、「保存」で元の `.md` ファイルへ書き込みます。色だけの変更も未確認の差分として扱い、「戻す」「確認済み」を使えます。未選択時とコードの文字には適用しません。

保存形式は、文字色が `<span style="color:#3984d5">文字</span>`、マーカーが `<mark style="background-color:#fff2a8">文字</mark>` です。両方を重ねることもできます。これらの対応タグと6桁の16進数色だけを解釈し、任意のHTMLやCSSは実行しません。対応タグ以外は文字として表示します。

Markdown標準には文字色・マーカーの指定がないため、GitHubやほかのプレビューでは色が再現されない場合があります。指定した色はテーマによらず同じ色で保存・表示します。パレット内のプレビューで読みやすさを確認してください。差分で追加された色付き文字には下線を残し、文書に付けた色を表示します。

## 見出しで折りたたむ（0.8.0）

見出しの左の **⌄ / ›** を押すと、次の同じ階層以上の見出しまでを開閉します。子見出し・本文・表・画像・Mermaidをまとめて折りたたみ、子見出しの開閉状態も保持します。

- 上部のアイコンで **見出しをすべて折りたたむ / すべて展開**。ボタンにはツールチップと読み上げ名があります。
- 折りたたんだ見出しには、その中の **変更件数** を表示。「前の変更 / 次の変更」で移動すると、対象の見出しを自動で展開します。
- **Preview / MD** の切り替え、通常の本文編集、レビュータブの再読み込みでも開閉状態を引き継ぎます。
- 折りたたみは表示だけを変更します。Markdown・確認済み基準・Undo履歴に折りたたみ操作は保存しません。
- **変更箇所だけ表示** と併用できます。開閉できる見出しを残します。

対象は文書直下の見出し1〜6です。見出しのない文書や、引用・リストの中の見出しには開閉ボタンを出しません。見出し名・階層が変わった場合は新しい節として扱い、タブを閉じて新しく開いた場合も同じ見出しの開閉状態を復元します。Cursor標準プレビューへの追加ではなく、コマンド **Markdown Lens: 変更プレビューを開く** で開く拡張機能の画面で使用します。

## 表のワンタッチ操作（0.7.0）

本文の表でセルを選ぶと、その位置を枠で示し、表のすぐ上に「何行目・何列目」を表示します。

- **行 ＋ / ↑ / ↓**: 選んだ行の下に追加、1行上・下へ移動。
- **列 ＋ / ← / →**: 選んだ列の右に追加、1列左・右へ移動。見出し・値・配置も一緒に移動します。
- **ゴミ箱アイコン**: 選んだ行・列を削除します。見出し行と最後の1列は保護し、表全体の削除は「表」メニューで行います。Undoで復元できます。
- **表の下の「＋ 行を追加」「＋ 列を追加」**: セルを選ばずに、その表の末尾へ追加できます。
- 追加後は新しいセルへカーソルが移り、そのまま入力できます。移動後も移したセルにカーソルを保ちます。
- 移動では見出し行を固定します。端を越える移動・複数行列をまたぐ移動は無効になります。
- 操作は本文の差分に反映され、Undoで取り消せます。保存ボタンを押すまでファイルは保存しません。

番号列のセルを選んで **連番** をオンにすると、その表の指定列だけを1から採番します。行の追加・削除・移動後も振り直し、IDなど他の列は変えません。列を移動すると採番設定もその列についていきます。番号列そのものを削除すると採番を解除します。もう一度押すと解除し、現在の番号は保持します。

採番設定はこのレビュータブで保持し、タブの再読み込み時も復元します。タブを閉じて新たに開く場合は再指定してください。ソースや外部編集で見出し構成が変わった場合、同じ見出しの表が複数ある場合も誤適用を避けるため再指定が必要です。番号そのものは通常のMarkdownとして保存され、独自の記号や隠しデータは書き込みません。

従来の「表」メニューには、上の行・左の列への追加や削除・配置操作も残しています。結合セルはクイック操作の対象外です。

## 対応範囲

- 日本語・英語の本文、見出し、箇条書き、引用、コードブロック、Markdownの表。
- 構造が同じ段落や表は、文中・セル内に差分を表示します。
- 構造が変わった箇所は変更前後を表示します。URL・空白・装飾だけの差分もMarkdownソースで確認できます。
- 戻す単位は段落・リスト・表などのブロックです。複雑な置き換えは複数ブロックを一組として扱います。
- LF / CRLFの切り替えを含む変更は、改行コードの表示付きでファイル全体を一組として扱います。
- 開いているプレビューは、エディタ内の未保存変更と外部プロセスによる保存の両方を監視します。
- 比較元はプレビューを閉じてもエディタを再起動しても保持します。
- ファイル単位で比較します。複数ファイルはそれぞれプレビューを開けます。
- 1ファイル512KB・最大4,000ブロックが既定です。`markdownLens.maxFileSizeKB` で128KB〜4MBに変更でき、ブロック数の上限もサイズに比例します。大きな差分には処理時間の上限があります。

## 注意点

- 初回読み込み前の編集履歴は、Gitで管理していればGitの比較元で確認できます。Gitがない場合は、AIに依頼する前に監視の開始を確認し、必要ならスナップショットを保存してください。
- 変更したのが人か、どのAIかは判別しません。同じ作業フォルダのファイルの内容を比較します。
- 別のworktreeやクラウドでの編集は、そのフォルダを開くか変更を取り込んでから確認してください。
- ファイルの移動・名前変更では比較元を引き継ぎます（外部ツールによる移動は内容の一致で判定）。
- 外部画像の読み込みとHTMLの実行には対応しません。リンクは⌘/Ctrl+クリックで明示的に開いたときだけ遷移します。ローカル画像・Mermaid・数式は本文と各変更の比較欄でプレビューできます。Mermaidの編集はコードブロック内で行います。
- UIは日本語と英語です（VS Codeの表示言語に従います）。VS Codeのテーマ、狭いウィンドウ、キーボード操作に対応します。
- デスクトップ版が対象です。ブラウザ版・SSHなどのリモート環境は未検証です。

## データの保存

ネットワーク送信、テレメトリー、AI呼び出しはありません。比較元の全文・編集中の下書き・スナップショット・表示位置を、VS Code / Cursorが提供する拡張専用ストレージの `baselines` ディレクトリに保存します。プロジェクト内に履歴ファイルは作りません。比較元はエディタ・ワークスペースごとに独立しています。

削除されたファイルの保存データは、最後の更新から14日（`markdownLens.storageRetentionDays`）を過ぎると自動で削除します。コマンド「保存データを整理」で、存在しないファイルの保存データをすぐに削除できます。すべて削除する場合は、対象エディタの拡張ストレージで `iam74k4.markdown-lens-review` の `baselines` を削除してください。削除後は、次回プレビューを開いた内容から比較を開始します。

## ローカル版からの移行

0.11.0の拡張IDは `iam74k4.markdown-lens-review` です。旧ローカル版 `local-markdown-review.markdown-review` とは別の拡張として扱われ、自動更新・比較元・下書き・スナップショットの自動移行はありません。旧版で未保存の下書きを保存してから旧版を無効化し、新版をインストールしてください。旧版の保存データは削除せず保持してください。新版では、その時点の文書から比較を開始します。両版を同時に有効にするとコマンドが重複するため、片方だけを有効にします。

## 開発

Node.js 22.12以降を推奨（配布された拡張を使うだけなら別途Node.jsは不要）。

```sh
npm ci
npm run check
npm test
npm run build
npm run test:tables
npm run test:diagrams
npm run test:rich
npm run test:webview
```

`npm run test:webview` は、実際のWebview（外枠のHTMLとバンドル済みのUI）を模擬した拡張ホストと組み合わせ、記法の表示・確認操作・リンク・原文編集・英語表示をブラウザーで検証します。

VS Code / Cursorでリポジトリのルートフォルダを開き、F5で拡張開発ホストを起動します。

`npm run test:host` は独立したテスト用プロファイルで実際の拡張ホストを起動し、外部編集検知・部分的な復元・Undo・保存・比較元の保持、新規ファイル・名前変更・テキスト差分・要約・リンク診断・カスタムエディターを検証します。macOSではインストール済みのVS Code / Cursorを使い、それ以外ではVS Code安定版をダウンロードします（Linuxでは `xvfb-run -a npm run test:host`）。メッセージの言語は `MARKDOWN_LENS_LOCALE`（既定 `ja`）で固定します。

`npm run test:ui` はVS Codeの実際のWebviewでボタン操作・ダーク/ライトテーマ・狭い幅の表示を検証します。`MARKDOWN_REVIEW_TARGET=cursor npm run test:ui` も用意していますが、Cursorの新規プロファイルではログイン画面に遮られる場合があります。既存のログイン済みウィンドウでの手動確認と組み合わせてください。

配布用VSIXは `npx vsce package --no-dependencies --out markdown-lens-0.14.0.vsix` で生成できます。公開時にはpublisherを登録し、VS Code Marketplace / Open VSX向けの配布情報を設定してください。

設計上はVS Codeの安定版APIのみを使い、最低APIバージョンは1.96です。各エディタ・各OSでの互換性は、実際にテストした範囲に限られます。
